# Realistic Dummy Content AI

The **Realistic Dummy Content AI** module is an submodule of the [Realistic Dummy Content](https://www.drupal.org/project/realistic_dummy_content) module, which enhances dummy content generation in Drupal using AI. It automatically generates realistic **text_with_summary** and **image** field values with help from AI providers like **Google Gemini** and **Fireworks AI**.

## Features

- AI-generated text for `text_with_summary, text_long, string_long` fields.
- AI-generated images for `image` fields (We have to pre generate ai images using drush
  then realistic dummy content module select those images).
- Integration with the [AI module](https://www.drupal.org/project/ai) for multi-provider support.
- Works alongside the `devel_generate` module to automate content generation with realistic and smart content.

## Installation

1. **Install required modules via Composer**:
   ```
   composer require drupal/ai drupal/fireworksai drupal/gemini_provider drupal/devel_generate
   ```

2. **Enable modules**:

    1. Enable devel_generate module.

        ```
        drush en devel_generate
        ```

        Go to /admin/config/development/generate/content
        Generate some content and observe that body and image fields contain default dummy values.

    2.  Enable realistic_dummy_content module.

        download realistic_dummy_content module using composer

        ```
        composer require drupal/realistic_dummy_content
        ```

        ```
        drush en realistic_dummy_content
        ```

        Go to /admin/config/development/generate/content
        Generate some content and observe that body and image fields contain realistic dummy content values.

    3. Let us install and configure and verify realistic_dummy_content_ai

        ```
        drush en ai fireworksai gemini_provider devel_generate realistic_dummy_content_ai
        ```

3. **Configuring**:


    AI Provider Configuration

    1. Gemini (for text generation)
        Sign up at ai.google.dev.
        Go to Gemini API Docs.
        Click on Get a Gemini API key. Copy and go back to your drupal site.

        Visit /admin/config/system/keys and create a new key with your Gemini API key.
        Assign the key under /admin/config/ai/providers/gemini.

    2. Fireworks AI (for text-to-image)
        Sign up at Fireworks AI.
        Buy credits (required for API usage).
        Generate an API key at: Fireworks API Keys. Copy and go back to your drupal site.
        Create a new key under /admin/config/system/keys.
        Assign the key under /admin/config/ai/providers/fireworksai and configure at /admin/config/fireworksai/settings.

    3. Go to Default ai proider settings form /admin/config/ai/settings 
        Look for Chat section select Default Provider and Default Model.
        Look for Text To Image section select Default Provider and Default Model.

    4. You can verify chat and image generation functionality
       ai settings in admin/config/ai/explorers if ai_api_explorer module is enabled.

    5. realistic dummy content ai works in 2 step process.

        1. Generate AI images:-

        If you want to replace images with ai generated images then generate images using drush.
        Ensure realsitic dummy content ai module is enabled and clear drush cache.

        Usage:
        ```
        # drush cc drush
        # vendor/bin/drush rd_ai_images:generate-images <module> <field_path> <count> <prompt> [options]
        ```

        Arguments:-

        <module> (Required):
        The name of the Drupal module that provides the field for which you want to generate images. For example, realistic_dummy_content.

        <field_path> (Required):
        The field path where the generated images will be stored. This is typically a path like realistic_dummy_content/fields/node/article/field_image.

        <count> (Required):
        The number of images to generate. Example: 2 to generate two images.

        <prompt> (Required):
        The text prompt that the AI will use to generate images. For example, "create different varieties of cake".


        Options:-

        --overwrite (Optional):
        If specified, any existing images in the field will be replaced with the new ones generated by the AI. If not specified, existing images will be kept.

        --size=<size> (Optional, default 1024x1024):
        Specifies the size of the generated images. For example, 512x512 for smaller images or 1024x1024 for larger ones. The available size options depend on the AI provider's capabilities.

        Example Usage
        1. Generate 2 AI-generated images for a content field

        Generate 2 images based on the prompt "create different varieties of cake" and save them to the specified image field in your module's content.

        drush rd_ai_images:generate-images my_module realistic_dummy_content/fields/node/article/field_image 2 "create different varieties of cake" --overwrite --size=512x512

        2. Generate AI-generated images without overwriting existing ones

        Generate 3 images based on the prompt "a futuristic cityscape" and add them to the field without replacing existing images.

        drush rd_ai_images:generate-images my_module realistic_dummy_content/fields/node/article/field_image 3 "a futuristic cityscape" --size=1024x1024

        3 futuristic cityscape images generated at realistic_dummy_content/realistic_dummy_content/fields/node/article/field_image

        ** Enable realistic_dummy_content module and clear the cache **

        2. Text content generation.

        Go to content types /admin/structure/types and edit the content type.
        - you can edit field of type text_with_summary, text_long, string_long and in help text
        add prompt for ai to generate the content.

        For example:-
            * your content type is cake then in help text of body field of type text with summary you can add
            user prompt as "generate a 3 paragraph about a cakes".
            * your content type is real estate then in help text of body field of type text with summary you can add
            user prompt as "generate a 3 paragraph on latest housing designs".

    6. Go to /admin/config/development/generate/content
       Generate some content and observe that body and image fields contains ai generated values.


Notes :- 

    Currently Works with text_with_summary, text_long, string_long and image field types only.
    AI-generated content is created during devel_generate batch processing.
    This module processes the content after nodes are generated by devel_generate and realistic_dummy_content.
    Clear the cache (drush cr) if AI content is not applied.
    Gemini provides a free tier for text generation, suitable if we have few nodes to be generated.
    Fireworks and other providers may require paid credits for image and other ai services.

Supported Providers:-

    Gemini (Google) – Text generation
    Fireworks AI – Image generation
    OpenAI – Can be used for both text and image (configure via AI module)
    See AI module project page for all supported AI providers.
